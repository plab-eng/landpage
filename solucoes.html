Plugins Gratuitos para Revit

A Plataforma pyRevit

Nossas soluções utilizam o pyRevit, uma plataforma leve que funciona como uma engine para rodar scripts de forma eficiente dentro do Revit.

Não se preocupe: Caso você ainda não tenha o pyRevit ou o Python instalado, o nosso instalador configurará tudo automaticamente para você.

Export Schedules

Automatize a extração de dados do seu modelo Revit. Este plugin exporta tabelas Revit diretamente para Excel (.xlsx) via COM, sem a necessidade de abrir o modelo manualmente, economizando tempo precioso na elaboração de orçamentos e listas de materiais.

Python pyRevit Revit API Excel COM

Export Sheets

Gestão eficiente de entregas. Exportação profissional de pranchas para PDF, DWG e DWF em massa. Inclui organização automática em subpastas e vinculação de imagens em DWG, garantindo um As-Built limpo e focado em operação.
