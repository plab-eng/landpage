A suíte P-LAB para Revit, agora em C#

A suíte nasceu em pyRevit e hoje é um add-in nativo: mais rápido, sem exigir Python na máquina do cliente e com licença por módulo. Os dois plugins gratuitos continuam disponíveis.

C# / .NET .NET Framework 4.8 .NET 8 WPF Revit 2021–2026

O que muda com o add-in nativo

Sem dependências

Não exige pyRevit nem Python instalados. O add-in carrega junto com o Revit, como qualquer ferramenta nativa.

Mais rápido

Código compilado e transações otimizadas: operação em massa que antes travava o modelo agora roda em segundos.

Licença por módulo

Chave validada na própria máquina, sem servidor e sem conta Autodesk. Você contrata só os módulos que usa.

Calcula a queda de tensão percentual dos circuitos conforme a NBR 5410 e grava o resultado no parâmetro do elemento — o valor vai junto para a tabela e para a prancha.

NBR 5410
Vídeo em breve videos/queda-tensao.mp4

Vídeo em breve videos/transferir-circuitos.mp4

A Plataforma pyRevit

Os plugins gratuitos rodam sobre o pyRevit, uma plataforma leve que funciona como engine para scripts dentro do Revit. A suíte em C# não depende dele.

Não se preocupe: Caso você ainda não tenha o pyRevit ou o Python instalado, o nosso instalador configurará tudo automaticamente para você.
